# QQ表情包管家

一键存图 + AI 智能发图，完整的 QQ 表情包管理插件。

## 快速上手

跟 AI 说一句话就能存图：

> **「存为 呆滞脸.png」**
> **「把这个存为 可爱猫猫.gif」**

AI 会自动用 `<SaveImage>` 保存图片到本地表情库。  
以后聊天时 AI 会按你设定的概率自动发送表情包。

## 功能

| 功能 | 说明 |
|------|------|
| **存图** | 对AI说「存为xxx」即可保存QQ图片到本地 |
| **AI主动发图** | 按策略 + 概率 + 情绪加权，自动在回复末尾追加 `<qimage>` |
| **表情列表** | AI 用 `ListEmojis` 查看可用表情，自己选合适的发 |
| **防刷屏** | 冷却时间 + 连发限制 + 线程锁 |
| **策略模式** | 纯随机 / 平衡 / 保守 / 活跃，一键切换 |

## 原理

**职责分离：**
- 系统（插件）→ 决策引擎判断「能否发」
- AI → 自己选「发哪个」
- 兜底 → AI 没发且系统判定可发时，随机补一个

**决策链路：**
```
冷却检查 → 连发限制 → 策略调概率 → 情绪加权 → 真随机数 → 结果
```

**情绪加权：**
对话中出现「哈哈」「笑死」「呜呜」等关键词，临时增加概率，让 AI 在情绪高点更爱发表情。

## 配置项

| 配置 | 默认 | 说明 |
|------|------|------|
| 表情包目录 | `Storage/QQEmojis` | 存图和发图共用 |
| 基础概率 | 10% | 每次回复触发的基础概率 |
| 策略模式 | 平衡 | 保守=概率减半，活跃=加20% |
| 冷却时间 | 30秒 | 发完一次后等待多久才能再发 |
| 最大连发 | 1次 | 冷却时间内最多发几次 |
| 情绪加权 | 开 | 检测关键词动态加概率 |
| 冷却机制 | 开 | 是否启用冷却 |
| 连发限制 | 开 | 是否启用连发上限 |

## AI 可用函数

```
<SaveImage name="文件名.后缀">图片URL</SaveImage>    存图
<ListEmojis />                                         查看可用表情
```

## 安装

直接在alife插件市场中下载  或者  将 `Alife.Plugin.QQEmoji` 文件夹放入 Alife 的 `Storage/Plugins` 目录，在客户端重载模块即可。
